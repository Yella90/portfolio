# Portfolio — Laye Soma Doumbia

Portfolio personnel : mécatronique, automatisme, maintenance industrielle et développement web (Bamako, Mali).

Le site est une page HTML statique, sans dépendance à installer : ouvrir `index.html` dans un navigateur suffit.

## Trois profils

Un sélecteur en haut de la page adapte la présentation, les compétences et l'ordre des réalisations au poste visé. Chaque profil a son lien direct :

- `#mecatronique` : automatisme, électromécanique et robotique
- `#informatique` : développement web et logiciel
- `#industrie` : maintenance et production
